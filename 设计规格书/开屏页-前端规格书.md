## 1. 范围界定

### 1.1 在范围内（In Scope）
- 开屏 / 加载层的结构、样式、动画、进入交互。
- 替换现有 `开屏页.html` + `#splashFrame` iframe 方案。
- 进入后的过渡动画（交叉淡入到聊天界面）。
- 开屏链路上的死代码 / 演示文字清理（仅限开屏相关）。
- 离线约束在该层的具体落实（素材引用方式）。

### 1.2 不在范围内（Out of Scope）

> **重要边界**：开屏页是一个"纯展示 + 进入"层。它不应该知道 Hermes 的任何概念。它只负责：好看地出现 → 用户点进入 → 优雅地消失，把舞台交给聊天界面。

## 3. 目标体验（验收口径）

1. 打开 `DEAR.html`，立刻看到星空球开屏，深色背景**铺满整个视口，无任何白色亮条**。
2. **进入按钮从首帧起就可点击**（最多 150ms 内可交互），不依赖任何资源加载完成。
3. 点击进入后：开屏层 **opacity 1→0（约 500–700ms）+ 轻微 scale/blur**，聊天界面同步淡入，形成**交叉淡入**；动画结束移除 DOM 节点。
4. 全程**零网络请求**（除加载本地的 `DEAR.html` 与 `素材/` 内资源外），断网也能完整跑完开屏与进入。
5. 星空球动画在低端机也要流畅：掉帧时不卡 UI 线程；页面不可见时暂停渲染。
6. 不再出现"演示数据已停用 / 已接入·数据已同步到服务器"等残留字样。

## 4. 技术方案（给 AI 的实现指引）

### 4.1 结构：删 iframe，改内联加载层

- **删除** `开屏页.html` 文件本身。
- 在 `DEAR.html` 中，把 `<iframe id="splashFrame" src="开屏页.html">`（约 line 2240）整段替换为：
  ```html
  <div id="splash" aria-hidden="false">
    <canvas id="splashStars"></canvas>
    <div class="splash-orb"> <!-- 星空球视觉 --> </div>
    <div class="splash-greet" id="splashGreet"></div>
    <button id="splashEnter" type="button">进入</button>
  </div>
  ```
- `#splash` 用 `position:fixed; inset:0; z-index:9999; background: var(--bg-deep)`（深色，与 `DEAR.html` 的 `body` 背景同源，杜绝白条）。
- 删除原 `#splashFrame` 相关 CSS（约 line 2127-2135）与 `dear-splash-exit` 的 `postMessage` 监听链路（约 line 5264）——不再需要跨 iframe 通信。

### 4.2 进入逻辑：立即可点，去掉进度门禁

- 「进入」按钮**默认可见可点**：`#splashEnter { opacity:1; pointer-events:auto; }`，不要等任何进度。
- 移除 `开屏页.html` 里基于 `window.load` 的进度门禁（约 line 388-393）与 `.show` 放开逻辑。
- 进入处理（直接写在 `DEAR.html` 内，不再 `postMessage`）：
  ```js
  function enterApp() {
    var s = document.getElementById('splash');
    if (!s || s.dataset.entering) return;
    s.dataset.entering = '1';
    s.classList.add('leave');                 // 触发 CSS 淡出
    setTimeout(function(){ if (s && s.parentNode) s.parentNode.removeChild(s); }, 700);
    // 聊天界面若需初始化，在这里调用一次 initializeChat()
  }
  document.getElementById('splashEnter').addEventListener('click', enterApp);
  ```

### 4.3 星空球视觉：保留风格，压性能

- 保留你认可的"星空球"意象（中心光球 + 星点环绕 + 轻微视差 / Ken Burns）。
- **性能预算**：
  - 星点粒子数从原来的 `900 + 380 ≈ 1280` 降到 **120–180**（视觉够用，肉眼难分辨差异）。
  - 用 `requestAnimationFrame` 驱动；监听 `document.visibilitychange`，页面隐藏时 `cancelAnimationFrame` 暂停。
  - 不阻塞首帧：粒子初始化放在 `requestAnimationFrame` 里延迟一帧，保证「进入」按钮先可点。
- 配色沿用 `DEAR.html` 的 CSS 变量（`--bg-deep`、`--mg-*` 等），不要另起一套硬编码色值（避免和全局设计系统冲突——见框架文件）。

### 4.4 进入过渡：柔和交叉淡入

```css
#splash { transition: opacity .6s ease, transform .6s ease, filter .6s ease; }
#splash.leave { opacity:0; transform: scale(1.04); filter: blur(6px); }
/* 聊天主容器初始 opacity:0，监听 splash.leave 后加到 1，实现交叉淡入 */
```
- 过渡时长 **500–700ms**，缓动 `ease`，不喧宾夺主。
- 不要做 4.2s 那种超长退场（原 `开屏页.html` 约 line 399 的 4.2s 退场是"太长"的元凶之一）→ 控制在 0.7s 内。

### 4.5 离线约束

- 所有视觉素材（贴图、字体）用**相对路径**引用 `素材/` 目录，且确认这些文件随 `DEAR.html` 一起分发。
- **不引入任何外部 CDN**（无 `cdn.jsdelivr`、`fonts.googleapis` 等）。
- 字体：沿用 `DEAR.html` 已有的本地 `woff2`（项目里已有 95 个 woff2），不要新增网络字体。
- 若星空效果需要贴图，优先用 CSS 渐变 / canvas 绘制，避免额外二进制依赖。

### 4.6 问候语（可选保留）

- 原 `开屏页.html` 的 WELCOME 库（约 line 316-355，按时段给早/午/晚/夜问候）可保留为纯函数 `getGreeting(date)`，移植进 `DEAR.html`，**不要引入任何外部依赖**，纯本地计算。
