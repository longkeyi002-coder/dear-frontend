# UI 与动线设计规格书（给 AI 实现用 · 纯设计层）

> 适用对象：负责 DEAR 前端 UI / 交互实现的 AI / 开发者
> 范围：**仅视觉设计 + 导航动线**。Hermes 后端对接、API 契约、记忆/技能/MCP 数据接入**本轮不做**，详见《整体前端适配 Hermes 框架规格.md》（那份是更大的框架，本文是它的"UI/动线切片"）。
> 配套：开屏页逻辑见《开屏页-前端规格书.md》（本文复用其视觉结论，不重复逻辑）。

> **修订（2026-08-31 用户更正）**：DEAR 不是要"补上 Hermes 缺的能力"——Hermes 本身就带 dashboard（skills/mcp/kanban 都有）。DEAR 是用户**自己的 dashboard**：**移动端优先 + 符合用户个人审美**，把 Hermes 已有的能力接进来、用用户自己的壳重新呈现。因此本文的配色/风格（§2.1 星空蓝紫）只是**待你审美确认的提案**，不是定稿；全篇以"移动端优先 + 你的审美"为最高约束；审美**可自定义、且内置预设主题**（见 §2.1）。

## 0. 给龙龙读的执行摘要

这份只管两件事：**长什么样（视觉）** 和 **怎么走（动线）**。

- **视觉**：定一套统一的"设计令牌"（颜色/字号/间距/圆角/阴影），全部走 CSS 变量、只定义一次。修掉你提的"字体颜色大小重点字没预设"和"用 text-shadow 糊弄对比度"。星空球保留但降性能。
- **动线**：聊天是家；侧栏图标打开的页面是"浮在聊天上面的层"，**同一时刻只有一个**，关掉就回聊天，聊天不刷新、不丢。双击聊天区 / 按 Esc / 点空白 = 回家。这直接修掉你提的"页面覆盖"和"双击回不去"。
- **不碰**：后端、Hermes 接线、真实数据。这轮只把壳和动线做对。

---

## 1. 设计原则

1. **单一真相源**：所有视觉变量只在 `:root` 定义一次，JS 只改 CSS 变量值，绝不写死样式（修掉 `applyTheme` 硬编码覆盖的旧病）。
2. **对比度靠真色，不靠阴影**：删除 `body` 上的 `text-shadow` 糊弄；小字发虚改用真实前景/背景对比度解决。
3. **可点的都够大**：触控目标最小 44×44px（手机一加 12 友好）。
4. **状态真实**：连接/模型/权限用真实状态，不写死"已接入"。
5. **离线优先**：字体用系统栈，图标用内联 SVG 或本地，零外部 CDN。

## 2. 视觉设计系统（令牌表）

> 直接抄进 `:root`。AI 实现时所有组件引用这些变量，不得另起炉灶。

### 2.1 主题系统（可自定义 + 预设主题）

> 机制：所有视觉值只走 CSS 变量；**主题 = 一组变量值**，切换主题=换变量；**自定义 = 用户覆盖变量**（设置里取色器）。组件严禁写死 hex。

**预设主题（4 套，一键切换；默认 T1）：**

- **T1 深色治愈（偏绿）· 默认**
```css
--bg-base:#0A0F0C; --bg-elev-1:rgba(255,255,255,.04); --bg-elev-2:rgba(255,255,255,.07);
--border-soft:rgba(255,255,255,.08); --border-strong:rgba(255,255,255,.14);
--text-1:#E6EFE9; --text-2:#9DB0A6; --text-3:#617069;
--accent:#6FD3A8; --accent-soft:rgba(111,211,168,.16); --accent-glow:rgba(111,211,168,.5);
--user-bubble:rgba(111,211,168,.16); --ai-bubble:rgba(255,255,255,.05);
```
- **T2 浅色干净（无彩色、统一圆角方块）**
```css
--bg-base:#F2F3F5; --bg-elev-1:rgba(0,0,0,.03); --bg-elev-2:rgba(0,0,0,.05);
--border-soft:rgba(0,0,0,.08); --border-strong:rgba(0,0,0,.14);
--text-1:#1F2421; --text-2:#5A625C; --text-3:#8A908A;
--accent:#2B2F2C; --accent-soft:rgba(0,0,0,.06); --accent-glow:rgba(0,0,0,.1);
--user-bubble:rgba(0,0,0,.06); --ai-bubble:rgba(0,0,0,.03);
```
- **T3 暗色霓虹（高饱和）**
```css
--bg-base:#07070B; --bg-elev-1:rgba(255,255,255,.05); --bg-elev-2:rgba(255,255,255,.08);
--border-soft:rgba(255,255,255,.10); --border-strong:rgba(255,255,255,.18);
--text-1:#F2F2F7; --text-2:#B0B0C0; --text-3:#6E6E80;
--accent:#FF2E97; --accent-soft:rgba(255,46,151,.16); --accent-glow:rgba(255,46,151,.5);
--user-bubble:rgba(255,46,151,.16); --ai-bubble:rgba(255,255,255,.05);
```
- **T4 暖色柔和（暖橙）**
```css
--bg-base:#F6F1EA; --bg-elev-1:rgba(0,0,0,.03); --bg-elev-2:rgba(0,0,0,.05);
--border-soft:rgba(0,0,0,.08); --border-strong:rgba(0,0,0,.14);
--text-1:#2E2A25; --text-2:#6B6358; --text-3:#9A9082;
--accent:#E0905A; --accent-soft:rgba(224,144,90,.18); --accent-glow:rgba(224,144,90,.4);
--user-bubble:rgba(224,144,90,.14); --ai-bubble:rgba(0,0,0,.03);
```

**通用（所有主题共享）**
```css
--status-online:#4ADE80; --status-offline:#6B7385; --status-err:#F87171; --warn:#FBBF24;
```

- **默认 = T1 深色治愈（偏绿）**（设置可改）。
- **自定义**：设置页提供"强调色 / 底色"取色器，写入 CSS 变量覆盖层并持久化（localStorage 键名脱敏）；自定义不破坏预设，可一键还原。
- **禁止**在组件里写死 hex；所有颜色走上面变量。

### 2.2 排版
```css
:root{
  --font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC",
               "Microsoft YaHei", "Noto Sans CJK SC", "Segoe UI", sans-serif;
  /* 字号阶梯（px，便于非开发者审） */
  --fs-display: 26px;   /* 开屏标题 */
  --fs-h1: 21px;
  --fs-h2: 17px;
  --fs-body: 15px;
  --fs-sm: 13px;
  --fs-xs: 12px;
  /* 行高 */
  --lh-body: 1.6;
  --lh-head: 1.35;
  /* 字重 */
  --w-normal: 400;
  --w-medium: 500;
  --w-semi: 600;
}
```
- **重点字规范**：用 `--accent` 色 + `--w-semi`(600) 表现强调，**不要**纯加粗；长段强调可用 `accent-soft` 底色小药丸（chip）包裹。
- 正文 15px / 行高 1.6；标题 21px / 行高 1.35。小屏可整体缩 1px，不破比例。

### 2.3 间距 / 圆角 / 阴影
```css
:root{
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px;
  --sp-5:24px; --sp-6:32px; --sp-7:48px;
  --r-sm:8px; --r-md:14px; --r-lg:20px; --r-pill:999px;
  --shadow-1: 0 2px 8px rgba(0,0,0,0.25);
  --shadow-2: 0 8px 28px rgba(0,0,0,0.40);
}
```
- 层次只靠 `bg-elev` + 1px `border` + `shadow`，**不用 `text-shadow`**。

### 2.4 组件预设
| 组件 | 规范 |
|---|---|
| 按钮-主 | `background:var(--accent); color:#0A0E1A; border-radius:var(--r-pill); min-height:44px; padding:0 var(--sp-5)` |
| 按钮-幽灵 | 透明底 + `1px var(--border-strong)`；hover `--bg-elev-1` |
| 聊天气泡-用户 | 右对齐，`background:var(--user-bubble)`，`--r-lg`，最大宽 78% |
| 聊天气泡-AI | 左对齐，`background:var(--ai-bubble)` + `border-soft`，最大宽 78% |
| 输入框 | `background:var(--bg-elev-2)`，`--r-pill`，内边距 `--sp-3 --sp-4` |
| 浮层/抽屉 | `background:var(--bg-base)` 或 `bg-elev-1` + `border-soft` + `shadow-2` |
| 状态点 | `width:8px;height:8px;border-radius:999px`，颜色取 status-* |

## 3. 开屏页视觉（复用于《开屏页-前端规格书》）

- **底色**：`--bg-base` 深空，铺满整个视口，**无白条**（已靠统一底色从源头解决）。
- **星空球**：保留"星点 + 发光球"意象；光晕用 `--accent-glow` 径向渐变。性能预算见开屏文件（粒子 1280→120–180，隐藏即暂停）。
- **进入按钮**：立即可点（去进度门禁）；样式用"按钮-主"预设；落在球下方居中。
- **过渡**：点击后 `opacity 1→0`（~600ms）+ 轻微 `scale(1.02)`/`blur(4px)`，之后移除节点；与聊天主界面**交叉淡入**。

## 4. 动线设计（导航_flow）

### 4.1 主路径
```
[开屏] --进入(立即可点)--> [聊天主界面]
  聊天是"家"，常驻不卸载
```
- 开屏只出现一次（会话内）；之后直接是聊天。

### 4.2 浮层模型（修"页面覆盖"）
- 侧栏/底部导航的入口（人格 / 技能 / MCP / 日记 / 系统 / 记忆 / 日历 / 周期 / 数据 …）打开的是**覆盖在聊天之上的浮层**，**不是跳页**。
- **全局仅维护一份 overlay 注册表**（数组/配置），所有可开页面在此声明一次；开关都从它来，杜绝双列表漂移（旧病：`closeAllOverlays` 漏 `dbPage`、`openAgentPage` 却 toggle 它 → 重叠）。
- 开新浮层前，**统一关掉当前浮层**（同一份列表）→ 任意时刻至多一个浮层。

### 4.3 回家方式（修"双击回不去"）
满足任一即关闭当前浮层、回到聊天（聊天不刷新、不丢上下文）：
1. **双击**聊天主区域；
2. 按 **Esc**；
3. 点击浮层**背景遮罩**；
4. 再次点击**当前已激活的导航图标**。
- 全局监听这四种；浮层关掉即"回家"。

### 4.4 常驻状态区（真实状态）
- 顶部或侧栏常驻一小条：连接状态点（online/offline/err）、当前模型名、权限级别。
- **数据来自真实状态**，不写死"已接入 · 数据已同步到服务器"（那是演示残留，已列入清理）。

### 4.5 首次引导
- 首次进入给**一句轻柔提示**（指向侧栏 + 设置），非演示文案、可关闭、不阻挡。

## 5. 响应式与适配（**移动端优先**）

> 最高约束：**先为手机（一加 12，顶部居中挖孔）设计**，桌面作为"放大版"而非另一套。

| 场景 | 布局 |
|---|---|
| 手机（一加 12，顶部居中挖孔）**主战场** | 聊天满宽，输入固定底部；导航为底部 Tab 或底部上滑抽屉；开屏铺满视口无白条；全部触控目标 ≥44px |
| 桌面（兼容） | 聊天居中列（max-width ~720px）；导航可为侧栏固定图标列 |
| 通用 | 触控目标 ≥44px；安全区 `env(safe-area-inset-*)` 适配挖孔/底部；字体用系统栈 |

- 开屏与 `body` 同 `--bg-base`，**任何视口下都不出现浏览器默认白底**。

---

## 6. 离线约束
- 字体：系统栈，无 web font 请求。
- 图标：内联 SVG 或本地 `素材/`。
- 第三方库（若引入 marked/DOMPurify）：本地打包，不引 CDN。
- 所有资源相对路径，随包分发。

---

## 7. UI / 动线 验收清单

**开屏**
- [ ] 进入按钮**渲染即可点**，无进度门禁
- [ ] 任意视口下**无白色亮条**（底色统一 `--bg-base`）
- [ ] 点击后交叉淡出（<700ms）进入聊天
- [ ] 星空球动画离线可跑、隐藏即暂停、粒子 ≤180
- [ ] 整体 100% 离线

**动线**
- [ ] 同一时刻至多一个浮层，无页面重叠
- [ ] 双击聊天区 / Esc / 点遮罩 / 再点当前导航 = 回到聊天
- [ ] 回聊天时**对话不刷新、不丢**
- [ ] 浮层开关来自**单一注册表**，无双列表漂移

**视觉系统**
- [ ] 颜色/字号/间距/圆角/阴影全部走 `:root` 变量，组件无写死值
- [ ] 删除 `body` 的 `text-shadow` 糊弄，对比度靠真色
- [ ] 重点字用 accent + 600，无纯加粗堆砌
- [ ] 状态区显示**真实**连接/模型/权限，无"已接入"写死

**适配**
- [ ] 一加 12 视口与桌面均可用，触控目标 ≥44px
