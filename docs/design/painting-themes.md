# Painting Theme System

A painting is a themed functional space, not a one-to-one mapping to a Hermes page.

## Theme contract
Each painting theme should define at minimum:
- `background`
- `surface`
- `surfaceRaised`
- `text`
- `textMuted`
- `accent`
- `accentSoft`
- `frame`
- `glow`
- `texture`
- `atmosphere`
- `motionProfile`
- `decorativeMotifs`

## East Wing V1

### 《睡莲》 — Home
Intent: coming home, continuity, quiet intimacy.
Palette direction: lake green, mist blue, soft pink, lavender, pale warm light.
Motifs: water surface, reflection, floating leaves, paper notes, subtle ripples.
May change with time, weather, season, relationship milestones and Home State.
Do not turn it into a dense KPI dashboard.

### 《日出·印象》 — Chat
Intent: everyday communication; morning mist and warmth.
Palette direction: mist blue, muted slate, warm orange/salmon accent.
Motifs: horizon line, fog, reflection, soft sunrise glow.
Chat readability is more important than painterly texture.

### 《撑阳伞的女人》 — Us
Intent: relationship history, diaries, anniversaries, emotional milestones.
Palette direction: sky blue, soft green, cream, white, restrained floral accents.
Motifs: breeze, grass, paper, ribbon, keepsakes.
Important relationship proposals may use a more ceremonial frame treatment.

### 《罂粟花田》 — Plans
Intent: goals and action without pressure.
Palette direction: meadow green, warm red accents, cream, open-sky blue.
Motifs: fields, paths, markers, pinned notes.
Task status must remain easy to scan.

### 《圣阿德莱斯的花园》 — Usage
Intent: resource awareness, clarity, spaciousness.
Palette direction: sea blue, garden green, warm cream, restrained coral accents.
Motifs: horizon, garden terrace, measured lines.
Charts should use a semantic data palette, not sampled painting colors that destroy distinction.

## West Wing direction
Use darker, quieter themes inspired by Parliament, Rouen Cathedral, Haystacks and Venice at dusk. West Wing is management/system territory, but still part of the same home world.

## Rule for new paintings
Add a new painting only when it represents a distinct user intention or spatial identity. If new functionality is semantically close to an existing space, extend that painting instead of adding another frame.
