## 一、卡牌视觉语言（真实考据，给设计定调）

### 1.1 卡牌物理结构（动画原设）
- **比例**：近似方形略高（动画里约 1:1.2 ~ 1:1.4，标准 TC 卡 63×88mm=1:1.4）。原型建议 **1:1.35**，手机网格 2~3 列。
- **正面（库洛牌）自上而下**：
  1. **外框金线花纹**（流动的金色藤蔓/卷草描边）——这是「库洛牌」最标志性识别元素。
  2. **四角小星**（橙色/金色四角星，固定在四角）。
  3. **顶部**：金色大太阳（内含该牌的**符号/星座印记**）+ 太阳左右各一弯**残月**。
  4. **中央**：紫色渐变背景 + 该牌的**代表性图形/精灵**（风=气流、水=水波…）。
  5. **底部缎带/卷轴**：写有卡牌名（英文大写，如 `THE WINDY`）。
- **背面（库洛牌）**：深红/绛红底 + 中央**库洛魔法阵圆环**（库洛·里德之印）+ 四角星。翻到背面即「封印态」。
- **小樱牌 vs 库洛牌区别**（转生后天绫设计）：
  - 库洛牌 = **红 + 金**（背面深红、外框橙金）。
  - 小樱牌 = **粉 + 金**（背面粉红、外框粉金，更圆润可爱）。
  - 这正好对应 DEAR 的 **昼(奶粉底+樱粉)/夜(近黑+樱粉)** 双主题——可把「库洛红金」当昼、「小樱粉金」当夜，或反过来。

### 1.2 太阳牌 / 月亮牌 + 四大元素（可用于「常驻态/家」的语义）
- **太阳属性牌**：由可鲁贝洛斯（守护者·阳）掌管 → 偏「行动/外接/主动」（光、风、火、雷、剑…）。
- **月亮属性牌**：由月（守护者·阴）掌管 → 偏「内省/记忆/静默」（暗、水、梦、眠、影…）。
- **四大元素牌**（可当 4 个主分类图标）：风 `WINDY` / 水 `WATERY` / 火 `FIREY` / 地 `EARTHY`。
- **可映射到 DEAR 常驻态**：连接/模型/权限 = 阳；记忆/日记 = 阴——给顶部状态条一个「日月徽记」的由头。

### 1.3 给 DEAR 的配色提取（不抄原色，借语义）
| 原作语义 | 原作色 | DEAR 复用为 |
|---|---|---|
| 库洛外框金线 | 橙金 `#E8B04B` | 各类别色描边（见 §四 8 色） |
| 中央紫背景 | 紫 `#6B4E9E` | 卡面中央 sigil 底色（浅化） |

## 四、可落地的 CSS / 前端实现参考

### 4.1 翻牌 3D 卡（可直接抄，来自公开 CSS 教程，已验证套路）
核心三属性：`perspective`（父，建 3D 空间）+ `transform-style: preserve-3d` + `backface-visibility: hidden`；翻面靠 `rotateY(180deg)`。`hover` 翻 or `click` 加 `.flipped` 翻皆可。

```html
<style>
.card { width: 200px; height: 280px; perspective: 1000px; }
.card-inner { position: relative; width:100%; height:100%;
  transition: transform .6s; transform-style: preserve-3d; }
.card.flipped .card-inner { transform: rotateY(180deg); }
.face { position:absolute; inset:0; backface-visibility:hidden;
  border-radius:14px; display:flex; flex-direction:column;
  align-items:center; justify-content:center; }
.front { /* 卡面：类别色描边 + 中央 sigil + 功能名条 */ }
.back  { transform: rotateY(180deg); /* 背面：一句话 + 翻开按钮 */ }
/* 悬浮轻微倾斜（锦上添花，可省） */
.card:hover .front { transform: rotateX(8deg); }
@media (prefers-reduced-motion: reduce){ .card-inner{transition:none} }
</style>

<div class="card" onclick="this.classList.toggle('flipped')">
  <div class="card-inner">
    <div class="face front">…卡面…</div>
    <div class="face back">…说明+翻开…</div>
  </div>
</div>
```

### 4.2 金边花纹卡面 = SVG 组件化（关键结论）
真实库洛牌的「金线外框 + 四角星 + 头顶太阳残月 + 魔法阵」**全部用 SVG 画一次**，35 张卡只换中间 sigil 与配色——这正是 `amriikk/ClowCards-React` 的做法（见 §4.3）。不要每张出图，做成一个 `<ClowFrame>` SVG 组件：
- 外层 `<rect>`/`<path>` 金线描边（类别色）；
- 四角各放一个四角星 `<path>`（可旋转复用）；
- 顶部一个太阳圆 + 左右残月弧；
- 中央一个 `<symbol>`/`<use>` 槽位放该功能的 sigil（emoji 或 SVG 图标）；
- 底部一条 `<rect>` 缎带写功能名。
- `prefers-reduced-motion` 下翻牌动效直接切显不转。
