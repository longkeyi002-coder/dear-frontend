# DESIGN.md · DEAR 功能页布局方案（治愈绿 · 浅色 · 友好版）

## 1. 画布与母版（A/B/C 三区，全程统一）
- 画布 1280×720，padding 上下 20、左右 72。
- **A 标题块** 0–120px：主标题 32–36px bold，左对齐，距左 72。
- **B 内容区** 120–660px（540px 高）：所有正文/图/卡。
- **C 页脚条** 660–720px：左侧项目名「DEAR 功能页布局方案」+ 右侧页码 `NN / 11`，14px 灰字。
- 封面 / 结论 / 对比推荐页允许自定义版式（省略 C 区或弱化）。

## 2. 颜色系统（治愈绿浅色，≤4 主 hex + 强调）
| 角色 | hex | 用途 |
|---|---|---|
| 主色 bg | `#F5F9F6` | 页面底色（浅薄荷白） |
| 辅色 panel | `#E3EFE8` | 卡片/分区底色（柔绿） |
| 强调 accent | `#2E9E6F` | 仅焦点：对勾、星标、关键数字、激活态 |
| 文本 ink | `#1E2B24` | 主文字（近黑绿） |
| 文本 muted | `#5E6E66` | 辅助说明（灰绿） |
| 描边 line | `#CFE0D6` | 卡片/分隔线 |

**色彩面积分配**：主色(底)≤60% · 辅色(卡)≤30% · 强调≤10%（hero 页可达 15–20%）。全篇比例有起伏：封面/结论偏强调，列表/对比偏辅色。

**渐变与半透明**：标题区可用 `linear-gradient(135deg,#2E9E6F 0%,#6FD3A8 100%)` 作细色带；卡片用 `rgba(46,158,111,0.06)` 浅绿底增强分区；装饰块 opacity 0.1–0.2。

## 3. 字体系统
- 标题/正文统一人文黑体：`"PingFang SC","Microsoft YaHei",sans-serif`（亲切、清晰）。
- 层级：封面主标 60–72px bold；章节大字 48–56px；页主标 32–36px bold；卡片小标 22–24px 600；正文 18–20px regular；脚注/页码 14px。
- 差异靠字重+字号+强调色，不用纯加粗堆砌。

## 4. 信息密度
- 常规页留白 ≤35%；封面/结论/对比可放宽至 40–50%（围绕焦点）。
- 每页 ≥1 视觉锚点（≥44px 元素或 ≥40% B 区图）：封面大标题、结论大对勾、方案页手机线框、对比页大表。
- 卡片组用 Flex 均分，尾部标签钉底（justifyContent space-between）。

## 5. 配图
- 全部用 **SVG 线框/示意图**（手机、浮层、分组、对比），属允许的结构化低语义图，不引外部图。
- 统一线框语言：圆角方块、2px 描边 `#CFE0D6`、激活态填充 `#2E9E6F`、文字 `#5E6E66`。
