# DEAR 功能排布与动线方案（卡牌收藏馆 · 卡片/抽屉结合）

> 主题：**百变小樱魔术卡**（35 功能 = 35 张魔法卡）。形态：**结合**——常看钉底部 Dock，偶尔收进分类抽屉（牌册），功能卡做封面；聊天是「牌桌中央常驻的伙伴」。
> 配套：依据 `DEAR功能总清单.md`（35 功能素材）+ `DEAR视觉方向参考.md`（主题方向）。本文是「动线/落位」切片，下一步才进代码。

## 1. 卡牌设计系统（每张功能卡的模样）

**底色（两套同树，仿 kimi-room NOX/DIES）**
- 日间 `DEAR·昼`：奶粉底 `#FDF6F9` + 墨 `#2B2B33` + 樱粉 `#E8729A`
- 夜间 `DEAR·夜`：近黑底 `#16121A` + 暖白 `#EDE6E0` + 樱粉 `#E8729A`
- 布局不动，只换色；默认随系统深浅。

**卡面结构（正面 / 背面翻牌）**
- 正面：类别色边框 + 中央 sigil（星/桃心/月等图标）+ 功能名（用户语言）+ 角标类别色点。
- 背面（点开翻牌）：一句话「这是啥」+ 入口按钮「翻开」。
- 翻牌动作用 CSS `transform: rotateY` + 星光闪（sparkle），`prefers-reduced-motion` 下直接切换不翻。

**类别配色（一眼区分功能族）**
| 类别 | 色 | 涵盖 |
|---|---|---|
| 伙伴/家 | 星金 `#E8C36B` | 聊天、连接态 |
| 记录 | 樱粉 `#E8729A` | 日记/日历/周期/数据/记忆 |
| 工具 | 天空蓝 `#7FB5E6` | 工具箱/终端/MCP |
| 编排 | 薄荷绿 `#6FD3A8` | 子代理/goal/handoff/cron/权限 |
| 连接 | 薰衣草 `#B79CE0` | 平台连接器 |
| 安全 | 蜜橙 `#F0A868` | 密钥/扫描 |
| 系统 | 银灰 `#A8B0AE` | 系统控制台/换模型 |
| 自有 | 桃心红 `#E8607A` | 人格(soul) |

**字体**：中文圆体（站酷快乐体 / 系统圆体）+ 西文 Quicksand/Nunito（活力亲和，契合 Sakura 俏皮治愈）。

## 2. 动线（导航流）

```
[开屏] → [牌桌·聊天(家，常驻)] 
   ├─ 底部 Dock：常看功能卡（日记/日历/记忆…）随手点
   ├─ 上滑/侧栏「牌册」抽屉：偶尔功能按类分册，点卡翻牌进浮层
   └─ 设置：换模型/终端/权限/密钥（藏深点）
点开任意卡 → 覆盖在聊天之上的浮层（同一时刻仅一个）
回家四法：双击聊天区 / 按 Esc / 点浮层背景 / 再点当前卡 → 回聊天（对话不丢）
```

- **单一 overlay 注册表**：所有可开功能卡在一份配置声明，开新卡先关旧卡，杜绝叠住（修旧 bug）。
- **指令隐形化**（借 Aion）：Hermes 指令 `[MUSIC:]`/`[TOY:]` 等前端实时隐去，用户只看到结果（音乐卡/💭 气泡）。
- **系统胶囊**（借 Aion/kimi-room）：自动化结果插居中系统消息（「📅 已建闹铃」），用 1-bit 小票风（借 kimi-room Ephemera）。

## 5. 对照 review-design 的 IA 自检

- **按用户任务分组**（非后端模块）：工具/编排/连接/安全/系统/记录/自有 七册，对应人想干的事 ✓
- **主/次/三级导航清晰**：Dock(主,常看) → 牌册(次,偶尔) → 设置(三级) ✓
- **无孤儿功能**：35 个全部落到 Dock/牌册/设置/常驻，无遗漏 ✓
- **一致的家**：聊天恒为家，浮层单一注册表、回家四法 ✓
- **视觉一致性**：统一卡牌系统（同结构、类别色编码），不个别特例 ✓
- **可发现性**：常看一键达；偶尔进册；设置藏深但不丢 ✓
- **动效克制**：翻牌/sparkle 仅装饰，reduced-motion 降级 ✓
