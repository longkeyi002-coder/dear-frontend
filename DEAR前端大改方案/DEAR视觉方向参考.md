# DEAR 视觉方向参考（开源借鉴 + 大胆主题）

> 目的：在排 35 个功能的动线之前，先定「视觉主题」。本文汇总两个开源参考的可借鉴套路，并结合你给的风格灵感（百变小樱魔术卡 / 梵高名画 / 悲惨世界）给出几套可落地的「大胆方向」供挑选。
> 方法：参考 ≠ 抄袭。只借「经过验证的好交互」，视觉主体用你选的主题重新画。

---

## 一、两个开源参考（已核实）

### 1. `marikagura/kimi-room`（AI 陪伴 PWA，本地优先）
**可借鉴的交互套路**：
- **「房间」模块化首页**：6 个可勾选上首页的房间（记忆星图 / 纪念 / 书架 / 日历 / 记忆审核 / 对话），其余落底部——对应 DEAR「常看放首页、偶尔收起」。
- **昼夜同树切换（NOX/DIES）**：布局不动，只换色板（近黑金 ↔ 暖羊皮纸玫瑰）。DEAR 可直接复用这个「换肤不换骨架」思路。
- **拉丁文小标签美学**：CTX / MEMORIA / IMPENSA / NOX… 强化「古典伴宠感」——DEAR 的状态区/费用条可套用。
- **语义气泡色**：自己=玫瑰(右) / 对方=金(左) / 系统=灰，固定语义。
- **Ephemera 热敏小票**：纯 SVG+CSS 1-bit 打印动效，零状态——适合 DEAR 的「系统提示/自动化结果」呈现。
- **装饰克制**：SVG 颗粒叠层 ~4% 透明、`mixBlendMode: overlay`；`prefers-reduced-motion` 全停。

**视觉**：慕夏暗金风——近黑底 `#0c0c0c` + 暗金 `#c4a060` + 玫瑰 `#8b3a3a` + 暖灰白字 `#d8d0c8`；衬线标题（Cormorant Garamond）+ 日文衬线。

### 2. `death34018-hue/AionsHome`（Aion，760★ 自托管伴侣）
**可借鉴的交互套路**：
- **手机主页 = 应用图标网格 + Dock 栏**（心语/密语时刻…当 App 图标）——DEAR 的 35 功能可做成「图标网格 + 常驻 Dock」。
- **指令隐形化**：`[MUSIC:]`/`[TOY:]` 等前端实时 strip，用户只看到结果（音乐卡 / 💭 气泡）——DEAR 的 Hermes 指令也应「只给结果」。
- **系统胶囊消息**：自动化操作插居中系统消息（「📅 已创建闹铃」），风格统一。
- **主题色指示器**：生图=橙 / 查看监控=紫 / POI=蓝，强化「伴侣主动感」的动效反馈。
- **本地优先 + 隐私**：数据全本地，离线安装包——与 DEAR 底线一致。
- **拟人化细节**：秘密日记、唤醒语音、背景记忆浮现。

**视觉**：暖光主题；小剧场=茶色暗色；动态壁纸页。

## 二、三套大胆方向（你挑或融合）

### 方向 A · 「卡牌收藏馆」（百变小樱魔术卡）★ 推荐
- **核心隐喻**：35 个功能 = 35 张魔法卡。首页是「牌库/牌桌」，每张卡有专属图标与色彩；点开卡面翻牌 → 进入该功能（浮层）。
- **色板（可改）**：奶粉底 `#FDF6F9` / 墨 `#2B2B33`；樱粉 `#E8729A` + 天空蓝 `#7FB5E6` + 星金 `#E8C36B`；闪点/星光点缀。
- **字体**：圆润人文黑体（中文）+ 带点童话感的西文；重点字用金。
- **动线**：聊天是「牌桌中央常驻的伙伴」；其余卡掀开=浮层（沿用回家四法）。常看的功能钉在 Dock/常驻行，偶尔的收进「牌库抽屉」。
- **为什么适合**：把「排列组合 35 功能」这件事本身变成玩法；最贴合你桌宠的桃心/俏皮治愈调，也最符合「做成卡片」。

### 方向 B · 「名画沉浸」（梵高星空 / 慕夏暗金）
- **核心隐喻**：UI 浮在名画质感的背景上——星空的漩涡、向日葵的暖、慕夏的金线。
- **子选项 B1 梵高星空**：深蓝底 `#0B1A30` + 星黄 `#E7C24B` + 丝柏绿 `#2E6F5E` + 暖白字；笔触纹理叠加。
- **子选项 B2 慕夏暗金**（kimi-room 已验证优雅）：近黑 `#0c0c0c` + 暗金 `#c4a060` + 玫瑰 `#8b3a3a` + 衬线标题。
- **字体**：衬线标题（Cormorant/Garamond 类）+ 日文衬线；拉丁小标签（MEMORIA/NOX 那套）。
- **动线**：功能做成「房间/抽屉」，每张功能卡用一段画作的局部当氛围底。

### 方向 C · 「雨果戏剧 / 呐喊」（文学表现主义）
- **核心隐喻**：悲惨世界的冷蓝烛火、海报连戏剧场感；呐喊的表现主义强色块只作「强调态」（报错/告警）平时克制。
- **色板**：冷蓝 `#1B2A4A` + 烛火暖 `#E0A93B` + 墨 `#0E0E12`；呐喊红 `#E3503E` 仅用于告警。
- **字体**：戏剧海报感衬线 + 小型大写标签；功能当「幕/章」展开。
- **调性**：最戏剧、最"重"，适合想要强烈情绪表达。

### 我的建议（融合）
**方向 A 为骨（卡牌式功能入口，最贴合「排列组合」），方向 B 为名画质感背景（星空/慕夏暗金作氛围）**——既有百变小樱的俏皮治愈，又有名画的质感厚度，且借了 kimi-room/Aion 验证过的「图标网格+Dock+房间+语义色」套路。你定主调后我再据此排 35 功能动线。
