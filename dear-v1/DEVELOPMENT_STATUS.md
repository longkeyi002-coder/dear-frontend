# DEAR V1 开发状态

## 已完成

- 建立 Vite + React + TypeScript 工程，旧单文件源码保持不动。
- 开屏页：本地球体素材、立即可点进入、移动端全屏背景。
- 聊天主页：聊天为家、假数据回复、输入发送、模型/权限/连接状态展示。
- 底部 Dock：聊天、日记、日历、记忆。
- 牌册：35 个功能入口按类别用统一魔法卡展示。
- Overlay：单一状态、同一时间最多一个、遮罩/关闭/Esc/双击聊天区返回。
- Hermes 预留：`src/services/api.ts` 使用 mock API，后续替换为 Hermes/BFF 接口层。
